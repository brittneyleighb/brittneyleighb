# Profile artwork and typography

The GitHub README uses **one unified graphic**: `assets/profile-composite.svg` (editable vector source) and `assets/profile-composite.gif` (animated published version, generated by GitHub Actions).

Typography:
- **Large name lettering:** restored to the original clean Arial/Helvetica sans-serif style.
- **Small all-caps headings and labels:** Greek Font Society **GFS Didot** editorial serif, stored as inline SVG outlines so visitors don't need a particular font installed.
- **Falling code glyphs:** intentionally monospace because they represent code, not interface labels.
- The graphic is inspired by Commodus, but does **not** include the commercial Commodus font. The Didot outline source uses the SIL Open Font License 1.1. No font file is committed.

Content:
- The Matrix rain animates in the generated GIF.
- The contribution bars and count are updated from GitHub's real public contribution calendar, for a rolling 90-day window.
- The lower project branches represent categories, **not** actual software dependencies.

Implementation:
- `scripts/build_profile.py` updates the single SVG and creates the GIF.
- `.github/workflows/contribution-pulse.yml` triggers that generator daily and after renderer changes to `main`.
- `scripts/update_pulse.py` remains as the data-fetching utility; the previous separate images are retained only as historical assets and are no longer embedded in the README.

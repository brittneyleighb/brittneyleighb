# Graphics typography

Display lettering in the three profile graphics uses vector outlines from **GFS Didot** by the Greek Font Society, an open-licensed Greek-inspired Didot typeface.

- Typeface: GFS Didot (Greek Font Society, 2007)
- License: SIL Open Font License 1.1
- Source of the vector outlines: `/usr/share/fonts/opentype/didot/GFSDidot.otf` in the design environment (not distributed with this repository)
- Application: BRITTNEY, LEIGH BANNING, PROJECT TOPOLOGY, and CONTRIBUTION SIGNAL
- Small technical labels remain monospaced for readability.
- The outlined headings render consistently in GitHub images without installing a font.

This is an **original Commodus-inspired typographic treatment**, not the proprietary Commodus typeface. No font file has been committed. The Matrix GIF is regenerated by the GitHub Actions workflow when its editable SVG changes.
